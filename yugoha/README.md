# yuGoHA 0.5.0

Локальный сервер уведомлений для Home Assistant и Android yuGoHA без центрального облака.

## Возможности с текущим Android yuGoHA 1.0

Home Assistant App автоматически устанавливает/обновляет встроенную интеграцию, регистрирует discovery, при первой установке один раз перезапускает Home Assistant Core и предоставляет действие `yugoha.send`.

Сохраняются все функции версии 0.4.5: FCM через Firebase пользователя, локальные HTTP/WebSocket, история, read/delete и синхронизация. Белый IP не требуется; при CGNAT новые сообщения приходят через FCM.

`Home Assistant → yugoha.send → yuGoHA App → Firebase пользователя → FCM → Android`

## Новые возможности сервера 0.5.0

- nullable-поле `recipient` безопасно добавляется к существующей SQLite-базе;
- получатель назначается каждому телефону в Web UI;
- `recipient` в `yugoha.send` выбирает одно или несколько устройств с этим значением;
- отсутствие/пустое значение отправляет всем, как раньше;
- неизвестный получатель не вызывает ошибку и возвращает ноль доставок;
- необязательные `server_id`/`server_name` заложены для будущего multi-server.

Маршрутизация `recipient` уже совместима с Android 1.0: её выполняет сервер. Настройка получателей из приложения и работа с несколькими HA-серверами потребуют следующей версии Android.
