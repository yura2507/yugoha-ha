# yuGoHA 0.5.0 — установка и настройка

## Установка и функции текущего Android yuGoHA 1.0

1. Откройте **Настройки → Приложения → Магазин приложений**.
2. Добавьте репозиторий `https://github.com/yura2507/yugoha-ha`.
3. Установите и запустите App **yuGoHA**.
4. При первой установке дождитесь единственного автоматического перезапуска Home Assistant Core.
5. В Web UI загрузите `service-account.json` своего Firebase-проекта.
6. В Android укажите локальный адрес, например `http://192.168.1.200:8098`, введите код сопряжения и подключите телефон.

Текущий Android получает FCM-уведомления вне локальной сети и использует HTTP/WebSocket для истории, прочтения, удаления и синхронизации. Центрального облака yuGoHA нет; Firebase-проект принадлежит пользователю. Старые API, поля и автоматизации сохранены.

Обычная отправка всем устройствам:

```yaml
action: yugoha.send
data:
  message: "1.info. Проверка yuGoHA"
  title: "Home Assistant"
  priority: 5
```

## Новые возможности сервера 0.5.0

В Web UI в карточке телефона заполните поле **Получатель**, например `yura`. Одно имя можно назначить нескольким устройствам.

```yaml
action: yugoha.send
data:
  message: "Открыта дверь"
  recipient: "yura"
```

Сервер отправит FCM и WebSocket-сигнал только устройствам с `recipient: yura`. Если поле отсутствует или пустое, сообщение отправляется всем как раньше. Неизвестное имя не ломает автоматизацию: ответ успешный, адресатов и доставок — 0.

Android 1.0 менять для этой серверной маршрутизации не нужно. Управление получателями с телефона и несколько HA-серверов потребуют следующей версии Android. Необязательные `server_id` и `server_name` в 0.5.0 являются только совместимым заделом.
