# yuGoHA 0.4.5 — установка и настройка

## Установка Home Assistant App

1. Откройте **Настройки → Приложения → Магазин приложений**.
2. Добавьте репозиторий:
   `https://github.com/yura2507/yugoha-ha`
3. Установите App **yuGoHA**.
4. Запустите App.

> **Важно:** при первом запуске yuGoHA автоматически устанавливает интеграцию `yugoha` и один раз перезапускает Home Assistant Core. Кратковременная недоступность интерфейса Home Assistant в этот момент нормальна.

После запуска App сам устанавливает/обновляет интеграцию и регистрирует её через Supervisor discovery. Отдельно копировать `custom_components` не требуется.

## Firebase

1. Откройте Web UI yuGoHA.
2. Загрузите `service-account.json` из своего Firebase project.
3. Убедитесь, что Project ID отображается на странице yuGoHA.

## Подключение Android

1. На Android откройте **Настройки → yuGoHA Server**.
2. Укажите локальный адрес Home Assistant, например:
   `http://192.168.1.200:8098`
3. При сером IP внешний адрес можно оставить пустым.
4. Введите 6-значный код сопряжения из Web UI yuGoHA.
5. Сопрягите телефон.

Новые сообщения доставляются через FCM даже вне локальной сети. Прочтение, удаление и история хранятся локально на Android и синхронизируются с yuGoHA Server при доступности Home Assistant.

## Отправка сообщения из автоматизации

```yaml
action: yugoha.send
data:
  message: "1.info. Проверка yuGoHA"
  title: "Home Assistant"
  priority: 5
```

Существующие автоматизации с `action: yugoha.send` менять не требуется.
