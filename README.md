# yuGoHA

Репозиторий Home Assistant App и встроенной интеграции **yuGoHA 0.5.0**.

yuGoHA — локальная система уведомлений для Home Assistant и Android без центрального облака yuGoHA. Пользователь устанавливает только Home Assistant App; интеграция `yugoha` устанавливается и настраивается автоматически.

## Возможности с текущим Android yuGoHA 1.0

- отправка уведомлений действием `yugoha.send`;
- доставка новых сообщений через Firebase пользователя и FCM;
- локальные HTTP/WebSocket, история, прочтение, удаление и синхронизация;
- работа при сером IP/CGNAT без белого IP;
- полная совместимость существующих автоматизаций и сопряжённых телефонов.

## Установка и обычная отправка

Добавьте `https://github.com/yura2507/yugoha-ha` в магазин приложений Home Assistant и установите App **yuGoHA**. При первом запуске App автоматически устанавливает интеграцию и один раз перезапускает Home Assistant Core.

```yaml
action: yugoha.send
data:
  message: "1.info. Проверка yuGoHA"
```

## Новое в сервере 0.5.0

В Web UI каждому телефону можно назначить необязательное имя `recipient`, после чего сервер маршрутизирует FCM и WebSocket-сигнал только соответствующим устройствам:

```yaml
action: yugoha.send
data:
  message: "Открыта дверь"
  recipient: "yura"
```

Пустой или отсутствующий `recipient` по-прежнему означает отправку всем. Неизвестный получатель безопасно даёт ноль адресатов. Это уже работает со старым Android 1.0, потому что выбор устройств выполняет сервер.

Управление получателями из Android и подключение нескольких HA-серверов появятся только в следующей версии Android. Сервер 0.5.0 лишь добавляет совместимые необязательные `server_id` и `server_name`; они не требуются текущему клиенту.
